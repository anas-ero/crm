
This project is a dynamic web application built using React, managed with Redux for global state, and styled with Tailwind CSS.

The core philosophy of this project is modularity and scalability. We adopted a strict "Separation of Concerns" methodology, ensuring that business logic is decoupled from the UI, and every visual element is broken down into small, reusable components.

--Tech Stack
Frontend Framework: React.js

State Management: Redux (Redux Toolkit)

Styling: Tailwind CSS

Icons: [React Icons]

Routing: React Router DOM

-- Key Features
-- Granular Component Architecture



Reusability: UI elements are built to be reused across different pages, ensuring design consistency and reducing code duplication.

📂 Modular Structure (Separation of Concerns)
Organized Workflow: The codebase is structured to separate view layers (UI) from logic layers (State).

Scalability: The file structure allows for easy maintenance and future feature additions without cluttering the main logic.

Clean Code: Custom hooks are used to handle logic, keeping component files clean and focused solely on rendering.
